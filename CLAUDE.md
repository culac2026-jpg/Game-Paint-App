# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project status

**GameArt Studio** is a Windows desktop editor for 2D game assets (raster painting + vector, pixel art, sprite animation, atlas export to Unity/Cocos Creator). The code is at the **v1.0** milestone: canvas, zoom/pan, Pencil, Brush, Eraser, Fill, Eyedropper, layers, undo/redo, project Save/Open, PNG export, selections (rect/ellipse/lasso, add/subtract/intersect/invert), move/free transform/flip/rotate/crop, layer masks, 18 layer/brush blend modes, brush dynamics (pen pressure, jitter, scatter, flat tips, stabilizer) brush presets, and non-destructive layer effects (color adjust, blur, pixelate, outline, drop/inner shadow, outer glow, color overlay), and the asset pipeline (image import, slices with pivots, auto/grid slicing, MaxRects atlas export for Unity/Cocos Creator/JSON, batch PNG export), and the animation timeline (frames with per-layer cels, durations, tags with forward/reverse/ping-pong playback, onion skin, multi-frame sprite sheets with a uniform pivot), and vector layers (Pen/Shape/Node tools, fill/stroke, SVG export) with 9-slice borders on slices, and the v1.0 hardening: crash recovery (autosave + backups), a C plugin API (filters/exporters) with a sample plugin, a QA suite (sample projects, fuzzing, undo stress) and a benchmark tool. The product/technical plan is `docs/GameArt_Studio_Ke_Hoach_Phat_Trien.docx` (Vietnamese, a proposal rather than a commitment) and is the source of truth for scope.

## Toolchain and commands

C++20, CMake ≥ 3.21 + Ninja, Qt 6.5+ (Widgets, OpenGLWidgets). On this machine the toolchain is **MSYS2 UCRT64** (GCC and Qt from `pacman`, in `C:\msys64\ucrt64`). There is no MSVC C++ toolset installed. Keep MSYS2 fully upgraded (`pacman -Syu`): MSYS2's Qt is built against the latest GCC runtime, and a partial upgrade makes Qt DLLs fail with `0xc0000139`.

Git for Windows puts its own `/mingw64/bin` (with older `libstdc++-6.dll`, `zlib1.dll`, etc.) ahead of `C:\msys64\ucrt64\bin` in the Bash tool's PATH. Prepend ucrt64 when building or running tools: `PATH="/c/msys64/ucrt64/bin:$PATH"`.

All executables go to `build/<preset>/bin`. After each app build (`GAS_DEPLOY_RUNTIME`, on by default on Windows), `windeployqt` copies the Qt DLLs and plugins there. Then `cmake/CopyRuntimeDlls.cmake` copies every other non-system DLL by name from the toolchain's bin directory, never from wherever PATH resolved it. So `bin/` is self-contained and the exe runs by double-click without MSYS2 on PATH.

```bash
cmake --preset debug                 # configure (build/debug); also: release, core-only (no Qt)
cmake --build --preset debug         # build app + tests
ctest --preset debug                 # run all tests
ctest --preset debug -R Viewport     # tests whose name matches a regex
./build/debug/bin/gas_core_tests --gtest_filter='PencilTool.*'   # run tests directly
./build/debug/bin/GameArtStudio.exe
```

GoogleTest 1.15.2 is fetched by `FetchContent` at configure time (or found via `find_package(GTest)` if installed).

`gas_bench` (from `bench/`, option `GAS_BUILD_BENCH`) prints stroke latency per pointer event on 2048², full-composite, sample save/load times and peak RAM; build the release preset for real numbers (`cmake --build --preset release --target gas_bench`). `gas_bench --write-samples <dir>` writes the sample projects as `.gas` files. The sample plugin (`plugins/`, option `GAS_BUILD_PLUGINS`, plain C) is built into `bin/plugins/`; the plugin test loads that DLL.

## Code layout

- `src/core` → `gas::core` static library, namespace `gas`, headers under `include/gas/core/`. **Must not include Qt or OpenGL.** Its only dependency is zlib. All tests target this library.
  - `TiledImage`: sparse 256×256 RGBA tiles (`Rgba8`, straight alpha) held as **copy-on-write `shared_ptr`s**. Copying an image or holding `snapshot()`/`sharedTile()` is pointer sharing, and `editTile()` clones a shared tile before writing. Writes mark tiles dirty, and `takeDirtyTiles()` drains the set.
  - `Document`: layers bottom (index 0) to top, each with `LayerProps` (name, visible, locked, opacity) and a `TiledImage`. **Every change goes through the document** so it's undoable:
    - Layer methods (`addLayer`, `removeLayer`, `moveLayer`, `setLayerProps`, …) record steps.
    - Tools draw between `beginEdit()` (returns the active layer's image, or null if it's locked or hidden) and `endEdit(label)`. `endEdit` diffs tile pointers against the snapshot taken at `beginEdit`, so a step stores only the changed tiles.
    - History is capped by estimated memory (1 GiB by default), dropping the oldest steps first. Consecutive `setLayerProps` on the same layer merge into one step.
    - `isModified()` compares against `markSaved()`.
    - `revertEdit()` restores the edited image to its `beginEdit` state while keeping the edit open (StreamLine redraws the stroke this way, still one undo step).
    - **Selection** (`selection()`, `setSelection()` and friends are undo steps; `selectionGeneration()` bumps on every change). While a selection exists, `beginEdit()` hands tools a COW *scratch* copy; `syncEdit()` (call it after each tool step so the canvas shows progress) and `endEdit()` write `mix(original, scratch, coverage)` into the layer, so nothing outside the selection can change.
    - **Transform session**: `beginTransform()` lifts the selected pixels (or the layer's content bounds) into a `FloatingImage` and leaves a hole; `setTransform(Affine)` previews with Nearest; `commitTransform(interp)` makes one undo step (pixels + transformed selection); identity commit = cancel. Undo and other edits are refused while transforming (`busy()`). `flipContent`/`rotateContent90` are exact one-shot transforms.
    - **Copy/paste**: `copySelected(merged)` = active layer (or frame composite) pixels × selection coverage, document-sized, in place; `layerFromSelection(cut)` (Layer via Copy/Cut, one step: the cut erases via `eraseSelected` and adds the layer, folded by the private `combineLastSteps`); `pasteLayer(name, image)` adds a layer and deselects as one step.
    - **Layer frame**: `LayerProps::frame` (`LayerFrame{rect, pivot, offset, angle, sx, sy}`, box = `matrix()`·rect, anchor = pivot + offset) remembers a layer's transform box and anchor (a body part on its own layer, anchor on the joint). `commitTransform(interp, label, frame)` stores it in the same undo step (only the anchor moved = a "Set Anchor" step); `transformLiftsWholeLayer()` says whether the frame applies (no selection, or one covering all the content); `sanitizedFrame` bounds values; `crop` shifts the offset; saved as `LFRM` (v8, f64).
    - `crop(IRect)` re-tiles every layer and mask (shares tiles when the offset is tile-aligned), deselects, changes the document size.
    - **Slices** (`Slice{name, rect, pivot, border}`, `border` = 9-slice `SliceBorder{left, top, right, bottom}` in px, clamped so opposite borders fit; pivot relative to the rect, top-left origin, may lie outside): `setSlices()` replaces the whole list as one undo step (clipped to the canvas, pivots clamped; `merge` folds repeated same-label edits), `restoreSlices()` for loaders, `slicesGeneration()` for views. `crop` moves/clips them. `flattenedImage()` is the sparse composite that slicing/export read. `addLayer(name, image)` inserts a layer with content (import) as one step.
    - **Layer masks**: `Layer::mask` is an optional `TiledImage` painted like any layer; `maskValue()` maps it (unpainted = shown, black = hidden), multiplied into opacity at composite time when `props.maskEnabled`. `setEditingMask(true)` makes `beginEdit()` target the mask. Adding a mask while a selection exists reveals only the selection.
    - Rendering uses `compositeTile`/`compositePixel`/`flatten`, plus `takeDirtyTiles()`, which covers every tile after a structure change.
  - `Selection`: 8-bit coverage mask in COW 256×256 tiles (null = unselected, one shared constant tile = fully selected). Builders `all/rect/ellipse/polygon` (even-odd, analytic anti-aliasing), `combined(op)`, `inverted`, `transformed`, `cropped`, `feathered(radius)` (3-pass box blur of the coverage), `outline()` (merged boundary segments for marching ants; skips uniform tiles, so select-all on 16k² is cheap).
  - `Transform`: `FloatingImage` + `transformInto(dst, src, Affine, Interpolation)` (inverse-maps pixel centres; Nearest or premultiplied Bilinear). `Geometry.h` holds `IRect`, `RectF`, `Affine`, `mappedBounds`.
  - `Effects`: `Effect` (one struct, fields used per `EffectType`) lives in `LayerProps::effects`, so effect edits are ordinary undoable, mergeable prop edits. `renderEffects()` renders per destination tile from a region grown by `effectMargin()` (premultiplied float planes; 3-pass box blur; Felzenszwalb distance transform for outline/glow; pixelate cells aligned to the canvas origin). Order: filters (ColorAdjust/Blur/Pixelate) in stack order, then DropShadow < OuterGlow < Outline < content (+ColorOverlay) < InnerShadow.
  - Effect cache: `Document::effectImage()` keeps a per-layer `EffectCache` (in `Layer::effectCache`, shared by copies but self-validating). It compares `TiledImage::revision()` (a globally unique counter bumped on every write) and then COW tile pointers to find changed tiles, and re-renders only tiles within the margin. `takeDirtyTiles()` expands dirty tiles by the same margin. Layer pixels are never modified; `rasterizeLayerEffects()` bakes them on request.
  - **Animation**: `Document` holds `frames()` (durations), `tags()` (`FrameTag{name, from, to, direction}`, `TagDirection` append-only) and per layer `Layer::cels` (one `TiledImage` per frame). `Layer::image` is always the live cel of `activeFrame()`; `syncCels()` writes it back after execute/undo/redo. Every `Command` records its `frame` and undo/redo switch to it first. `setActiveFrame()` is a view change, not a step (refused while busy). Frame structure ops (`addFrame` copies the active duration and inserts after it, `duplicateFrame` shares COW tiles, `removeFrame`, `moveFrame` where the active frame follows its content, `setFrames`, `setTags`) go through `executeAnimation`, which snapshots the whole frame state. Tags grow when a frame is inserted inside or right after them and are dropped when their only frame goes. Masks and effects are per layer, not per cel; `crop`, `applyLayerMask` and `rasterizeLayerEffects` process every cel. `flattenedFrame(f)` composites any frame; `historyGeneration()` bumps on every change (view caches key on it).
  - **Vector layers**: `Layer::vector` (`shared_ptr<const VectorShapes>`, null for raster layers). The layer's image is always the rasterization of its shapes, so compositing, masks, effects and every export work unchanged; shapes are the same in every frame (`fillVectorCels` copies the image to all cels). `addVectorLayer`, `setVectorShapes(i, shapes, label, mergeToken)` (one undo step, unchanged tiles keep their pointers; equal non-zero `mergeToken`s fold a drag into one step), `rasterizeVectorLayer`. `beginEdit()` refuses vector layers (except mask editing); a transform commit on a vector layer transforms the shapes (selection ignored); `crop` translates them; `applyLayerMask`/`rasterizeLayerEffects` turn the layer into a raster one.
  - `Vector`: `PathNode{p, in, out}` (absolute cubic handles; corner = handles on the point), `VectorPath{nodes, closed}`, `VectorStyle` (fill/stroke colours, width, `LineJoin`/`LineCap` append-only, miter limit 4, `antialias`), builders `rectanglePath` (rounded)/`ellipsePath`/`polygonPath` (stars via inner ratio), `flattenPath`, `hitTestShapes`, `transformedShape(s)`. `renderShapes` = nonzero scanline with 5 sub-rows and exact horizontal coverage (no AA: pixel centre in/out); a stroke is a union of convex pieces (segment quads, joins, caps), so overlaps never double-blend. `svgPathData`/`svgPathElement`. `sanitizedShapes` clamps coordinates to ±`kMaxVectorCoordinate` and widths to `kMaxStrokeWidth` (applied by `addVectorLayer`, `setVectorShapes` and the loader) and `flattenCubic` stops at depth 12, so rendering time stays bounded for any input (found by fuzzing).
  - `Recovery`: `RecoveryStore` keeps per-session autosaves (`<dir>/<session>.gas` + `.info` text with the original path/title/time, project written first so entries are complete or absent); `entries()` newest first, `remove()`. Session liveness is the app's job (lock files).
  - `Plugins`: the C ABI lives in `include/gas/plugin/GasPlugin.h` (pure C, structs only grow, `structSize` checked; plugins export `gas_plugin_api_version` and `gas_plugin_init(GasHost*)` and register `GasFilter`s (edit an RGBA buffer of the selection bounds or whole canvas, typed params INT/FLOAT/BOOL/COLOR/CHOICE) and `GasExporter`s (get a `GasDocument` view with layer/slice info, frame durations, `renderFrame`/`renderLayer`, `writePng`)). `PluginHost` loads DLLs (`LoadLibraryExW`/`dlopen`) or in-process init functions, copies everything registered, rejects duplicates/invalid data and drops a failed init's registrations. `applyPluginFilter` runs a filter as one undo step via `beginEdit`/`endEdit` (values clamped, missing ones = defaults, only changed pixels written, failure reverts); `runPluginExporter`.
  - `SampleProjects`: `buildSampleProjects()` makes five deterministic documents (pixel-art animation, 10-layer illustration with mask/effects/selection stroke, vector UI kit with 9-slice slices, 4096² sparse canvas, tileset with grid slices) used by the QA tests and the benchmark.
  - `ProjectIO`: `.gas` save/load (chunked little-endian binary (v2 adds `LMSK` layer-mask chunks, v3 adds `LPRP` layer-property chunks holding the blend mode, v4 adds `LEFX` effect stacks, v5 adds `SLCS` slices, v6 adds `FRMS` frames/durations, `CELS` cels of frames 1..n-1 (LAYR tiles are frame 0) and `TAGS`; v8 adds `LFRM` layer frames; v7 adds `VECT` shapes (a vector layer's LAYR has no tiles and it has no CELS; the image is re-rasterized on load) and `SLBD` slice borders; older versions still load), zlib-compressed non-empty tiles, CRC-32 trailer, format version, unknown chunks skipped; the layout is documented in `ProjectIO.h`). `serializeProject`/`parseProject` are the in-memory forms (`parseProject` must never crash or allocate unboundedly on hostile bytes; the fuzz test feeds it mutated files with fixed-up CRCs). `saveProject(doc, path, {.backup = true})` keeps the replaced file as `<path>.bak` (`backupPathFor`). Values the file stores as f32 (layer opacity, effect parameters, slice pivots) are rounded to float precision when they enter the document, so Save/Open is exact (the sample round-trip test compares bytes and pixels). `exportPng` (a self-contained PNG encoder), `svgDocument`/`exportSvg` (vector layers as paths; raster layers and vector layers with a mask or effects as trimmed base64 PNG `<image>`s; opacity, `mix-blend-mode`, layer names as `<title>`) and all saves go through `writeFileAtomic` (temp sibling + rename). Bump `kProjectFormatVersion` for incompatible changes.
  - `Slicing`: `gridSlices` (cells inside the image, skip empty), `autoSlices` (8-connected islands of alpha > threshold, boxes merged within `mergeDistance`, islands under `minPixels` dropped), `trimmedRect`, `sortReadingOrder` (greedy rows), `namedSlices` (`base_00`...), `uniqueName`, `copyPixels`, `nineSliceScale` (corners kept, edges/centre stretched or tiled; the right/bottom parts are measured from the outer edge).
  - `Atlas`: `packAtlas` = MaxRects best-short-side-fit; each item occupies trimmed size + 2×extrude + padding inside a bin of page − 2×border + padding; candidate page sizes are tried smallest area first (POT pairs, or growing near-squares), overflow fills a max-size page and continues on the next, pages shrink to what they use. Sprites with a 9-slice border are never trimmed and carry `border` (JSON `"border"`, Unity `spriteBorder` x=left y=bottom z=right w=top). Frames keep `source` (trim rect within the original sprite), `sourceWidth/Height` and the pivot (source-relative). Metadata: `atlasJson` (TexturePacker JSON hash + pivot), `cocosPlist` (format 2; offset = trimmed centre − source centre, y up; no pivot), `unityMeta` (TextureImporter spriteMode 2; rects from the bottom; pivot converted to the trimmed rect with y up so it stays on the same source pixel; guid/spriteIDs hashed from the file/sprite names so re-exports keep references). `AtlasPreset` (Unity, Unity pixel art = point filter/PPU 16, Cocos Creator, Generic) and `AtlasFormat` are append-only. `exportAtlas` writes `<stem>.png` (or `<stem>_<n>.png` per page) plus metadata; `exportSlicePngs` (trim, integer nearest scale), `exportLayerPngs` and `exportFramePngs` (PNG sequence) are the batch exports. Animation: `spritesFromFrames` (every frame of every slice, or whole frames with one pivot when there are no slices; `AtlasSprite::duration`), `tagsForFrameSprites` (per slice `<slice>_<tag>`), `AtlasSettings::grid`/`columns` (equal untrimmed cells in input order, so the pivot is the same cell pixel in every frame); the JSON writes per-frame `duration` and `meta.frameTags`. All file names go through UTF-8 `u8string` paths and `safeFileName`.
  - `Viewport`: `screen = doc * zoom + offset`, `zoomAt` keeps the anchor point fixed. Use `toPixel()` (floor) for doc→pixel.
  - `StrokeTool`: the begin/moveTo/end interface for drag tools, taking doc-space `PointF`. It also carries a `Symmetry` (read at `begin`).
  - `Symmetry`: mirror painting modes (Vertical/Horizontal/Quad/Radial/Kaleidoscope, append-only enum) expanded by `copies()` into `SymmetryCopy` (flip across the vertical line through the centre, then rotate; multiples of 90° use exact cos/sin). `BrushTool::stampSymmetric` stamps every copy of each dab into the *same* stroke mask (copies never stack), with mirrored centre/angle and `Dab::flipped` flipping the tip's local y so asymmetric tips mirror; wet-mix colour and smudge buffers are kept per copy (smudge cells indexed with symmetric `lround`). The pencil mirrors pixel by pixel when all copies are grid-aligned (exact pixel-art mirrors) and draws one line per copy for other rotations.
  - `PencilTool` / `drawLine`: Bresenham, overwrites pixels. Each `moveTo` connects to the previous pixel so fast strokes have no gaps.
  - `BrushTool` (Paint or Erase mode): stamps dabs every `spacing × dab diameter` px, carrying leftover distance across events. Each stroke keeps a per-tile coverage mask (max of coverage × dab opacity, not sum) plus a COW copy of each tile as it was when the stroke first touched it. Pixels are recomputed from that copy (with `blendPixel` and the brush's blend mode), so one stroke never exceeds its opacity. `BrushSettings` also holds the dynamics: tip shape (`BrushShape`: Round/Square/Diamond/Triangle/Hexagon/Star as distance or polygon-gauge functions with a numeric-gradient 1 px AA edge, or Custom = a `BrushTip` coverage image made by `brushTipFromImage`, e.g. Edit > Define Brush Tip; tips compare by content and are base64 in preset files), pressure → size/opacity (pressure is interpolated along segments), size/opacity/angle jitter, scatter, roundness/angle/follow-direction (flat tips anti-alias via the ellipse's distance gradient), smoothing. Randomness is a SplitMix64 seeded per stroke (`setSeed`), never `<random>` distributions, so output is identical on every platform; every dab draws the same number of random values.
  - Media (`BrushSettings`): `grain` (canvas-anchored value-noise paper texture, so one stroke never fills its pits), `particles` (airbrush dots from a per-pixel hash of the dab index), `mix` (wet paint: picks up the pre-stroke colour under the dab, per tip diameter travelled, ignoring transparent pixels), `BrushShape::Bristle` (fixed streak profile across the tip). `BrushMode::Smudge`/`Blur` reuse the tip coverage but work progressively on the current pixels (premultiplied; smudge carries a buffer centred on the dab; `opacity` = strength). Built-in presets start with the paint-program media set (Brush, Calligraphy Brush/Pen, Airbrush, Oil Brush, Crayon, Marker, Natural Pencil, Watercolor); the panel's preset menu shows a rendered stroke per preset.
  - `StrokeSmoother`: the stabilizer, applied by the input layer (canvas) before calling the tool; `finish()` returns the release point so strokes end where the pointer did. `streamlinePath()` (StreamLine) smooths a whole recorded stroke after the fact: 1 px arc-length resampling, then two Gaussian passes whose window shrinks near the ends so both endpoints stay put. A stroke whose last quarter comes back within `closeDistance` of its start (the canvas passes max(24 screen px, brush diameter)) is a closed shape: the overshoot is trimmed, the loop is smoothed cyclically and ends on its first point, so the join has no gap or kink.
  - `BrushPresets`: built-in presets plus a locale-independent `key = value` text format (unknown keys ignored, values clamped).
  - `floodFill`: scanline fill, **4-connected** on purpose, so it can't leak through the pencil's 8-connected diagonal lines. `pickColor` ignores fully transparent pixels.
  - `Blend`: `blendOver`, `eraseAlpha`, `mix`, `colorDistance`, `maskValue`, and `blendPixel(dst, src, BlendMode, coverage)` implementing the W3C Compositing spec formulas (separable + Hue/Saturation/Color/Luminosity). `BlendMode` values are stored in files: append only. Layers carry `props.blendMode`; golden values live in `BlendModeTest`.
- `src/app`: Qt shell.
  - `CanvasWidget` (a `QOpenGLWidget` painted with `QPainter`) keeps a per-tile cache of *composited* `QImage`s, refreshed from `Document::takeDirtyTiles()` on each paint and drawn nearest-neighbour; the cache is dropped when the document size changes (crop/undo). It wraps each stroke in `beginEdit`/`syncEdit`/`endEdit` and emits `documentEdited`. It owns the symmetry settings (not saved in the document; centre recentred when the canvas size changes, draggable handle snapping to half pixels, dashed guides), the selection-tool drags, the marching-ants outline (rebuilt when `selectionGeneration()` changes) and the free-transform box (state = pivot/offset/angle/scale, M = T(pivot + offset)·R·S·T(−pivot) → `Document::setTransform`; 4 corner + 4 edge handles scale about the anchor, outside rotates about it; the anchor ⊕ is draggable in half pixels (Shift snaps to corners/edges/centre) and moving it re-solves the offset so pixels stay put; `transformChanged` feeds the options bar fields Angle/W/H/Anchor X/Y/Center Anchor; selection tools show a Transform button). A whole-layer transform starts from the layer's `LayerFrame` when the content still lies within the box's canvas bounds (pixels get M·frame⁻¹, so the box opens rotated/scaled where it was left; otherwise a fresh box keeps the anchor) and stores it on commit once the layer has one or the anchor/angle/scale was set. Ctrl+Z/Ctrl+Y inside an open transform step through `transformUndo_`/`transformRedo_` (one entry per drag, field edit or nudge); Ctrl+Z past the start cancels the transform.
  - Slice tool (K): `CanvasWidget` draws slice boxes/names/pivots (always with the Slice tool, otherwise per View > Show Slices) and edits them with a preview `SliceDrag` committed on release (create on empty canvas, move, 8 resize handles keeping the pivot's canvas point, pivot drag in half pixels with Shift snapping to edges/centre; arrows nudge as a merged step; Edit > Clear/Delete removes the selected slice instead of pixels). The canvas owns the selected slice index (`selectedSliceChanged`).
  - 9-slice borders: with the Slice tool the selected slice shows dashed guides; drag a guide (or Alt+drag an edge to pull a new one out) to set the border (`SliceDrag::Mode::Border`).
  - `SlicesPanel`: dock (tabbed with Brush/Effects) listing slices; edits name/rect/pivot/9-slice border of the selected one (spin edits merge), a 9-slice Preview dialog (`MainWindow::nineSlicePreview`, `nineSliceScale` at any size, optional tiling), Trim (keeps pivots on the same canvas point), Pivot to All, Delete, Clear, and buttons for Auto/Grid slice and Export Atlas (dialogs live in `MainWindow`).
  - Import: File > Import Images (or image paths on the command line): one image = new document; several = one sheet of equal cells (largest image), each image centred and standing on its cell's bottom, one slice per file. Import as Layer uses `Document::addLayer(name, image)`.
  - `TimelinePanel`: bottom dock (the side docks own the bottom corners, so it sits under the canvas) with transport, frame edits, duration (+ apply to all), onion skin before/after counts and tags over a `TimelineGrid` (layers x frames, filled dot = painted cel; overlapping tags stacked in lanes; Shift+click frame numbers selects a range for a new tag; double-click a tag edits/deletes it). Playback is a single-shot `QTimer` per frame duration over the innermost tag containing the start frame (else all frames), locked when Play is pressed; it never switches frames during a stroke and stops on undo/redo. Shortcuts: `,`/`.` previous/next frame, Alt+P play/stop, Alt+N new frame, Alt+D duplicate, F3 onion skin. `CanvasWidget::setOnionSkin` draws tinted `flattenedFrame` images (earlier red, later blue, opacity 0.5/distance) under the frame, cached until `historyGeneration()` changes.
  - `VectorTools` (`VectorEditor` + `VectorOptions`): the Pen (P), Shape (J) and Node (A) tools (`isVectorTool`), owned by `CanvasWidget`, which forwards press/move/release/double-click/keys/paint/cursor while a vector tool is active. New shapes go into the active vector layer, or a new vector layer above a raster one. Pen: click = corner, drag = smooth, click the first node to close, Enter/double-click finishes, Backspace, Esc. Shape: rectangle (corner radius)/ellipse/polygon/star/line, Shift = square, Alt = from centre, box corners on whole pixels. Node: pick shapes on any visible vector layer (switches the active layer), drag shapes (whole pixels)/nodes (half pixels)/handles (mirrored; Alt breaks), Alt+click toggles corner/smooth, double-click the outline inserts a node (de Casteljau), Delete, arrows, Ctrl+[/] stacking. Each drag uses a fresh merge token so it is one undo step. `VectorOptions` (options bar) edits fill/stroke/width/join/anti-alias of new shapes and of the selected one (merged). Layer menu: New Vector Layer, Rasterize Vector Layer; File > Export SVG.
  - `LayersPanel`: dock showing the top layer first (vector layers have a node icon), with blend mode, opacity, lock and mask controls.
  - `EffectsPanel`: dock (tabbed with Brush) editing the active layer's effect stack; the list shows the last-applied effect on top and the form shows only the fields the selected type uses.
  - `BrushPanel`: dock with presets (user presets saved to `brush-presets.txt` in the app data folder via `QSaveFile`) and dynamics of the active Brush/Eraser; size/opacity/hardness stay on the options bar, and `settingsChanged` re-syncs it.
  - Pen pressure: `CanvasWidget::tabletEvent` only records `pressure()` and ignores the event, so Qt synthesizes mouse events that drive the tools; `pressureOf()` uses the recorded pressure for stylus-sourced mouse events and 1 for the mouse.
  - `MainWindow`: owns the `Document` and the file path. `onDocumentChanged()` re-syncs the title (`[*]` modified marker), Undo/Redo labels, the layers panel and the canvas. Connect anything that edits the document to it. The panel's signal is queued so the list isn't rebuilt inside its own item signal.
  - Crash recovery (`MainWindow`): each window has a session id (UUID) and holds `recovery/<session>.lock` (a `QLockFile` with stale time 0) in the app data folder; a 60 s timer (`GAS_AUTOSAVE_SECONDS` overrides) autosaves when the document is modified and `historyGeneration()` changed (skipped mid-stroke/transform). Saving or a clean close removes the autosave. `offerRecovery()` (called from `main` after `show()`) lists entries whose lock can be taken in `RecoveryDialog` (Recover / Delete / Not Now); a recovered document keeps its original path, is `markUnsaved()`, and is re-autosaved into the new session before the old entry is removed. Saves keep `.bak`; if opening fails and a `.bak` exists, the user is offered the backup.
  - Plugins (`MainWindow::loadPlugins`, `PluginUi`): DLLs from `bin/plugins` and the user's app-data `plugins` folder; the Plugins menu lists filters (parameter dialog generated from the params, last values remembered) and "Export ..." exporters, plus Open Plugins Folder and About Plugins (load errors and plugin logs).
  - Convert paths with `toStdWString()` so Vietnamese file names work. LMB goes to the active `Tool` (shortcuts N pencil, B brush, E eraser, G fill, I eyedropper, M rect select, O ellipse select, L lasso, V move, S smudge, R blur, K slice, P pen, J shape, A node; Q toggles StreamLine (options-bar strength; the canvas records raw samples, smooths live with the stabilizer, and on release reverts the edit and redraws along `streamlinePath`), U toggles straight-line mode (a drag previews a line and paints it on release; Ctrl at press does the same once; Shift snaps to 15° via `snapAngle`; Shift+click joins the last stroke's end to the click); `[`/`]` brush size; C colour). Shift/Alt/Shift+Alt at drag start = add/subtract/intersect. Ctrl+T free transform (Enter applies, Esc cancels), Ctrl+X/C/Shift+C/V cut/copy/copy merged/paste (`MainWindow::copySelection`/`paste`: the system clipboard gets the trimmed image plus `image/png` and an `application/x-gameart-studio-origin` "x,y,w,h" marker, so pasting into a canvas of the same size lands in place, otherwise centred in the view; paste always makes a new layer), Ctrl+J/Ctrl+Shift+J new layer via copy/cut, Delete clears, Alt+Backspace fills, Ctrl+A/Ctrl+D/Ctrl+Shift+I select all/deselect/inverse, Shift+F6 feather. `MainWindow::settleCanvas()` commits an open transform before save/export/close. The layer list has no keyboard focus so single-key shortcuts aren't swallowed by item search. MMB or Space+LMB pans, the wheel zooms at the cursor. `MainWindow` shows per-tool options (size/opacity/hardness, tolerance), and Brush and Eraser keep separate settings. Qt code is built with `QT_NO_KEYWORDS`, so write `Q_SIGNALS`/`Q_EMIT`, not `signals`/`emit`.
- `tests`: GoogleTest, one file per core class, plus `QATest` (sample-project byte-exact round trip, undo/redo of every sample, fuzzing of damaged files, a 120-step random edit session undone/redone state by state) and `PluginTest` (in-process and real DLL plugins).
- `plugins/sample`: the sample plugin in C (Invert, Grayscale, Posterize filters; Slices as CSV exporter).
- `bench`: `gas_bench`.

All first-party targets link the `gas_warnings` interface target (`-Wall -Wextra -Wpedantic -Wconversion -Wshadow`).

## Planned stack beyond v0.1

- Stroke and pixel work on the CPU first; move to the GPU gradually
- Outputs: PNG, sprite sheet + JSON metadata; SVG and other formats come in later phases

## Planned module architecture

| Module | Responsibility |
|---|---|
| Application Shell | Qt panels, docking, shortcuts, command palette |
| Document Core | Canvas, layer tree, property graph, undo/redo, autosave |
| Raster Engine | Tiled RGBA buffers, brushes, selections, fills, image filters |
| Vector Engine | Paths, geometry, tessellation, vector layers |
| Renderer | Compositing, viewport zoom/pan, texture cache, OpenGL backend |
| Animation | Timeline, per-frame cels, onion skin, preview |
| Asset Pipeline | Slicing, atlas packing (MaxRects), 9-slice, engine export, validation |
| Plugin API | Tool/effect/export extension points; AI features stay optional plugins |

**Key constraint:** keep the core (Document Core, Raster/Vector engines) independent of Qt and OpenGL so it can be unit-tested and the rendering backend can be swapped later.

## Technical decisions to honor

- **Tile-based storage:** prototype 256×256 px tiles; mark only the tiles a stroke or filter touches as dirty.
- **Undo/redo:** a command log for light operations and tile snapshots for large strokes; cap history by RAM usage.
- **Color/alpha (decided in v0.2):** pixels are *stored* as straight-alpha RGBA8, matching PNG and the `QImage::Format_RGBA8888` upload. Blend math premultiplies internally (`Blend.cpp`), and any pixel with alpha 0 is normalised to all-zero. Use golden-image tests for color/alpha correctness.
- **Brush:** resample the pointer path so strokes never break; add pen pressure/tilt only after mouse input is stable.
- **Project files:** a versioned schema storing layers, transforms, masks, effects and metadata. Saves must be atomic, with autosave and backups.

## Build order

The MVP comes first: custom canvas, Pencil/Brush/Eraser, Eyedropper, Fill Bucket, RGBA palette, zoom/pan, raster layers, undo/redo, project save/open, PNG with transparency. AI, bone animation, PSD fidelity and vector booleans are explicitly **out of MVP scope**.

Roadmap: v0.1 canvas/zoom/pan/checkerboard/Pencil → v0.2 Brush/Eraser/Fill/Eyedropper → v0.3 layers/undo/save-open → v0.4 selection/transform/mask → v0.5 brush dynamics/blend modes → v0.6 non-destructive filters/effects → v0.7 slicing/atlas/batch export → v0.8 animation timeline → v0.9 vector/Pen/9-slice → v1.0 (done) QA/performance/plugin API/crash recovery. Lock scope per version; each milestone has its own acceptance test in the plan doc.

## Acceptance criteria (from the plan)

- Fast strokes on a 2048×2048 canvas with no unexpected gaps
- 10 layers composite correctly (opacity, visibility, order)
- At least 20 consecutive undo/redo steps, and state survives Save/Open
- PNG export keeps exact size, colors and transparent pixels
- Selection/transform never touches pixels outside the selection
- Atlas export has correct metadata, padding and pivots per preset
- Test across Windows DPI/scaling levels; track stroke latency and peak RAM
